older-package

Termux (aarch64) için kişisel APT deposu.

1. Depoyu ekle

pkg update
mkdir -p $PREFIX/etc/apt/sources.list.d
echo "deb [trusted=yes arch=aarch64] https://mio-129.github.io/older-package/ stable main" \
  > $PREFIX/etc/apt/sources.list.d/older-package.list
pkg update
Sadece :: yerine aşağıdaki tek satırı kullanmak yeterli: 
echo "deb [trusted=yes arch=aarch64] https://mio-129.github.io/older-package/ stable main" \
  > $PREFIX/etc/apt/sources.list.d/older-package.list

Depo eklendikten sonra paket listede görünmeli:

pkg search vs-code
apt-cache policy vs-code

2. Kur

pkg install vs-code
VS Code, Termux'ta X11 (VNC / Termux:X11) gerektirir. Resmî olarak paketlenmiş sürüm için pkg install x11-repo && pkg install code-oss de kullanılabilir.
