older-package

Termux (aarch64) için kişisel APT deposu.

Durum: pkg install vs-code şu an 404 Not Found verir. Metadata doğru; eksik olan tek şey dosya: vs-code.deb 228.5 MB olduğu için GitHub'ın 100 MB'lık dosya sınırına takılır ve pool/ içine konamaz. GitHub Pages yönlendirme de yapamaz.

1. sources.list'i temizle

older.list + older-package.list mükerrer tanım uyarısı üretir; tek dosya bırak ve fazladan kelime yazma:

pkg update
mkdir -p $PREFIX/etc/apt/sources.list.d
rm -f $PREFIX/etc/apt/sources.list.d/older.list
echo "deb [trusted=yes arch=aarch64] <BASE_URL> stable main" \
  > $PREFIX/etc/apt/sources.list.d/older-package.list
pkg update

2. Çözüm A — Worker proxy (apt çalışır)

proxy/ altındaki Cloudflare Worker, /pool/* isteklerini GitHub Release asset'ine 302 ile yönlendirir; metadata Pages'te kalır.

# worker'ı yayınladıktan sonra (bkz. proxy/README.md):
BASE_URL=https://older-package.<hesabın>.workers.dev/

pkg install vs-code

Doğrulama:

curl -sI $BASE_URL/pool/vs-code.deb | grep -i ^location
# location: https://github.com/Mio-129/older-package/releases/latest/download/vs-code.deb

3. Çözüm B — Elle kurulum (hemen çalışır)

curl -L -o $TMPDIR/vs-code.deb \
  https://github.com/Mio-129/older-package/releases/download/1.0.0/vs-code.deb
pkg install $TMPDIR/vs-code.deb

4. Termux'ta çalışır mı?

Bu .deb Ubuntu/Debian için derlenmiş (glibc + GTK). Termux bionic libc kullanır; indirme düzelse bile CANNOT LINK EXECUTABLE / eksik libgtk-3.so.0 hataları beklenir. Termux için doğru yol: 
pkg install x11-repo
pkg install code-oss
